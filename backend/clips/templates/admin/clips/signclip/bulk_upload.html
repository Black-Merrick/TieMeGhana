Every file becomes the gloss its name is, with the extension dropped: head.mp4 becomes HEAD, what_is_your_name.mp4 becomes WHAT_IS_YOUR_NAME. A gloss that already exists gets this file as its new recording, and its approval is reset — whoever approved the old one has not seen this one. A gloss that does not exist yet is created.

Uploading exactly the same file again changes nothing, so a repeat upload can never un-approve a clip. The one exception is on purpose: tick “approved for clinical use” below and name the consultant, and a clip already uploaded and still awaiting review is approved, with its recording left as it is. A clip that was rejected stays rejected; approve it from the clip list.
